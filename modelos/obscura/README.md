# Obscura Skin Lab — cinematic model (work in progress)

Fictional skin studio in Brooklyn. One-page, scroll-driven WebGL film with an instrument/HUD look. No external libraries.

Open `index.html` through a local server (`npm run dev` from the repo root, then `/modelos/obscura/`).
