# Obscura Skin Lab — porcelain version (work in progress)

Same brand, copy and cinematic technique as `../obscura` (WebGL film, burn transitions, HUD, treatments reel, studio, demo booking), restyled with the Marlowe Rue palette and the Marlowe Rue photographs.

- Dark scenes (film, reel, footer): bordeaux #4A1E2A with champagne #D9C4A3 and porcelain #F5F0EE text.
- Light scenes (loader, studio, booking): porcelain #F5F0EE with bordeaux and rose-deep #8E5149 (class `tone-light`).
- The HUD switches between the two as you scroll.
